## Future Paths

- **CV Freshness Pipeline**: Automate PDF sync from main to mcp branch with hash-based freshness checks. Small effort, guards against stale content.
- **Professional Profile Hub**: Integrate GitHub stats and LinkedIn data alongside the CV for a living professional profile. High effort, high impact.
- **CV Diff and Changelog**: Surface CV changes over time via `get_cv_changes(since?)` tool. Enables "what's new" queries.
- **Tailoring Presets**: Pre-configured tailoring profiles for common job archetypes (Senior ML Engineer, Staff SWE, Engineering Manager). Each preset pre-weights sections and emphasis areas. Natural follow-on after the tailoring pipeline ships.
- **TailoringSpec Persistence**: Save TailoringSpecs for reuse across sessions. Enables re-rendering without re-analyzing. Could support a `list_tailoring_specs` / `get_tailoring_spec(id)` tool pair.
